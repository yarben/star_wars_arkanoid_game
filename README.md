# Star Wars: Arkanoid Game

A Star Wars themed Brick Breaker (Arkanoid) game built in C++ featuring dynamic level design and projectile splitting mechanics.

## Gameplay Features
* **Iconic Custom Levels:** Destroy blocks arranged in the shapes of the Death Star, Star Destroyer, and other classic ships.
* **Score & Upgrade System:** Earn points by hitting blocks and spend them on a mid-game power-up that splits all active projectiles on the screen.
* **3 Progressive Levels:** Increasing difficulty with strategic block layouts.
* **Immersive Atmosphere:** Thematic backgrounds accompanied by an epic Star Wars soundtrack.

## Tech Stack
* **Language:** C++
* **Graphics/Audio Library:** SFML

## Controls & Instructions
* Move your paddle side to side using the **Left / Right Arrow keys** ('←' / '→') to bounce the projectiles.
* Press the **Spacebar** to split all active projectiles currently on the screen.
